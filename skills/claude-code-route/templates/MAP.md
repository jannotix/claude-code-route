# Repository map

One per repository. The first file to read and the last one to let go stale.

An index, not a summary. Every entry carries `path:line` and the revision it was verified at. An
entry is a hint: confirm it by reading the range it points at before relying on it, and correct it
in place when it has moved.

Cap: roughly 400 lines. Beyond that, split by context or prune what nothing has touched in months.

Generated skeleton: `node scripts/route-map.mjs .` — then enriched one cycle at a time, never in a
sweep.
